# Toroidal Fractal Intelligence

A novel AI architecture based on continuous structured learning through toroidal fractal dynamics.

## Overview

ATOM (Toroidal Fractal Intelligence) creates intelligence through **dynamic structures** rather than static weights. The system builds internal structures from data, and these structures **are** the knowledge.

## Architecture

```
TOKEN → ATOM → SUPERPOSITION → DYNAMICS → INTERACTIONS
    → AGGREGATION → ABSTRACTION → CONSOLIDATION → OUTPUT
```

## Key Features

- **Infinite Learning**: No boundary between training and inference
- **Continuous Thought**: Internal reasoning before generation
- **Structural Emergence**: Atoms → Aggregates → Abstractions
- **Parameter Efficiency**: Shared rules control many structures

# Install
pip install -e .

python test/shakespeare_test.py

python src/main.py --mode train --max-steps 1000

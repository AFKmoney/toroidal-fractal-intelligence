# Zout — archived material

This directory contains material intentionally kept out of the active project surface.

- `docs-history/` — historical reports, old benchmarks, scaling studies, and work logs.
- `results-history/` — old generated benchmark outputs.
- `build-artifacts/` — generated Python bytecode and packaging metadata that were accidentally tracked.

Nothing in this archive is part of the active runtime path. Files are preserved rather than discarded so historical work remains recoverable.
